## Ce merge bine
- HTTP → HTTPS: `http://design.marketing-solutions.ro/contact/` → `301 https://…/contact/`. TLS 1.0/1.1 refuzate (`Cipher is (NONE)`), TLS 1.2/1.3 OK; cert Let's Encrypt valabil până `Dec 20 2026`.
- Consent Mode v2 corect: default `denied` pe toate 4 semnale + `wait_for_update:500` (`AnalyticsHead.astro:18-25`, confirmat în `dataLayer` live). Zero cookies și zero `g/collect` înainte de click; după Reject tot 0 cookies, 0 `collect`. După Accept: `gcs=G101` (analytics granted, ads denied) — Accept nu activează reclame.
- Nimic expus: `/.git/HEAD`, `/.git/config`, `/package.json`, `/astro.config.mjs`, `/README.md`, `/tools/analytics/package.json` → 404; `/assets/`, `/_astro/`, `/server-status` → 403 (fără listare); source map `…ClcPSQ7x.js.map` → 404; `Server: nginx` fără versiune.
- Zero mixed content: Playwright a înregistrat 0 cereri `http:` pe `/` și `/contact/`.
- `analytics.js` curăță datele: whitelist de parametri per eveniment, `mailto/tel` eliminate, query string șters din `link_url` (`analytics.js:68-74`); `innerHTML` din `contact.astro:148` folosește doar constante (fără input utilizator).

## Rezumat
Infrastructură curată (HTTPS forțat, TLS modern, nimic expus, Consent Mode v2 corect: 0 cookies/0 collect fără accept).
Lipsa juridică e cea mare: nicio politică de confidențialitate, formularul trimite date la FormSubmit (SUA) fără informare; zero headere de securitate în nginx.
Primele fixuri: pagină `/privacy/` + link în banner/formular (M), headere nginx (S), self-host fonturi (S), cache-busting pentru `consent.js` (S).
