```sh
npm ci
npx playwright install chromium   # for npm run test:audit
npm run build:web                 # writes ../web (production)
npm run check && npm run test:audit
```

  and rebuilt by `prebuild:web`.

## Release zip (Windows gotchas, both hit in this session)
- **Do not set `BASE_PATH=/` from Git Bash.** MSYS rewrites it to `C:/Program Files/Git/`, and the
  build links everything there. `check-dist` caught it as "link to English page /C:/Program%20Files/Git/".
  Use `npm run build:web` (it sets the env itself), or build from PowerShell:
  ```powershell
  $env:SITE_URL='https://design.marketing-solutions.ro'; $env:BASE_PATH='/'
  node node_modules/astro/astro.js build --outDir D:\web-release-<sha>
  ```
- Delete `content-assets.mjs` and `content-modules.mjs` from the output. They are 25-byte Astro
  leftovers and do not belong on the server.
- Run `node tools/audit/check-dist.mjs --html-dir <folder>` before zipping.
- **Do not zip with Windows `tar.exe -a`.** On 815 MB it wrote a corrupt archive
  ("ZIP decompression failed"). Python `zipfile` worked: store media files, deflate the rest,
  then check with `testzip()`.
